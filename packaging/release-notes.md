Voges Pencil: a simple paint program, in the spirit of the classic Paint, for macOS, Windows and Linux. Part of the Voges suite, next to Voges Word.

## What's new in Voges Pencil 1.0.2

- **Linux:** the window shows the app's icon in Alt+Tab and in window lists.

## Install

Page with the downloads and step-by-step instructions: https://omanoloneto.pro/voges/pencil/

- **macOS** (10.15 or newer, Apple Silicon and Intel): open `VogesPencil-macos.dmg` and drag Voges Pencil to Applications. The first time, macOS blocks the app because it is not notarized by Apple: go to System Settings → Privacy & Security → Open Anyway.
- **Windows** (10 or 11, 64-bit): run `VogesPencil-windows-setup.exe`; it does not need administrator rights. If SmartScreen warns you, click "More info" and then "Run anyway".
- **Linux** (Ubuntu 22.04, Debian 12 or newer and derivatives, 64-bit): `sudo apt install ./voges-pencil-linux-amd64.deb`

`SHA256SUMS.txt` lists the SHA-256 of each file, so you can verify the download, and `SHA256SUMS.txt.sig` is its signature.
